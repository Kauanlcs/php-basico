
# PHP Básico

Atividades práticas de Programação Web I (Técnico em Informática).

**Aluno:** Kauan Machado

## Projetos

- **01-hello-world:** primeira página em PHP.
- **02-data-hora:** exibição da data, hora e segundos.
- **03-imc:** calculadora de IMC com classificação.
- **04-produtos:** lista de produtos com preços, estoque e situação.

## Como executar

1. Instalar o Laragon e iniciar os serviços.
2. Colocar esta pasta em `C:\laragon\www\php-basico`.
3. Abrir [http://localhost/php-basico/](http://localhost/php-basico/) no navegador.
